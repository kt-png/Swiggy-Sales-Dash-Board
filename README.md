# 🍔 Swiggy Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Swiggy food delivery sales data using Microsoft Power BI. The objective is to transform raw food delivery data into meaningful business insights through interactive dashboards, KPI tracking, and data visualization.

The dashboard helps analyze sales performance, customer preferences, food categories, geographical distribution, and order trends to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor total orders and revenue.
- Identify top-performing cities and states.
- Understand customer food preferences.
- Analyze monthly and daily sales trends.
- Evaluate restaurant and food category performance.
- Develop an interactive sales dashboard.
